# Reader

从 [Sparks Releases](https://github.com/superprodami/sparks/releases/tag/reader-v2.0.0.4-mod.1) 下载修改版 Reader.exe，双击打开。原版 Windows 文本阅读器由 BinBin Yu 开发，上游源码见 [binbyu/Reader](https://github.com/binbyu/Reader)。

py/biquge345_download.py 是单独的辅助脚本。运行前安装 requests 和 beautifulsoup4，按需修改文件开头的书籍地址和输出文件名。输出为文本文件，可用 Reader 打开。
